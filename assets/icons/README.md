# assets/icons

Small, mostly-square marks — app icon variants and wallet-provider logos.

| File | Used on | Recommended size |
| --- | --- | --- |
| `logo.png` | Anywhere `AppLogo(useAsset: true)` is set | 256×256, transparent bg |
| `wallet_phantom.png` | Wallet connect list | 64×64, transparent bg |
| `wallet_solflare.png` | Wallet connect list | 64×64, transparent bg |

The app ships with a drawn logomark (a check inside a ring, see
`AppLogo` in `lib/core/widgets/app_logo.dart`) so none of these are required
to run the app — add them only if you want the raster versions instead.
