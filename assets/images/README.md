# assets/images

Drop image files here using the exact names below and they'll appear
automatically — every screen that uses them already falls back to a drawn
placeholder, so nothing breaks if a file is missing.

| File | Used on | Recommended size |
| --- | --- | --- |
| `onboarding_1.png` | Onboarding, slide 1 (paste a take) | 800×800, transparent bg |
| `onboarding_2.png` | Onboarding, slide 2 (AI compiles it) | 800×800, transparent bg |
| `onboarding_3.png` | Onboarding, slide 3 (trade & earn) | 800×800, transparent bg |
| `auth_art.png` | Welcome / sign-up screen hero art | 1000×1000, transparent bg |
| `empty_markets.png` | Empty state on the home feed | 600×600, transparent bg |
| `success_check.png` | Market-created / trade-confirmed success screen | 600×600, transparent bg |
| `wallet_connected.png` | Wallet screen, first-connect success | 600×600, transparent bg |
| `market_placeholder.png` | Fallback cover image on a market card | 800×600, any aspect close to 4:3 |

PNG or WEBP both work. Keep illustrations flat and on-brand: solid shapes in
Ink (#111426), Paper (#FBF8F1), Highlight (#FFD23F), Yes (#0B7F76) and
No (#D63645) — no gradients, no stock-photo people, no emoji, matching the
landing page.
